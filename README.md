# Borodianka Map
Навчальний прототип Leaflet із двома кольоровими нитками вздовж доріг Бородянки.

**Усі кольори — демонстраційні.** Проєкт не публікує фактичний стан електромережі.

## Запуск
1. GitHub → Actions → **Import OSM data** → Run workflow. Операція завантажить дороги з Overpass та закомітить `data/roads.geojson`.
2. GitHub → Settings → Pages → Source: **GitHub Actions**.
3. GitHub → Actions → **Deploy site** → Run workflow (або запушити зміни).
4. Відкрити `https://truephp.github.io/borodianka-map/`.

Overpass потрібен лише під час імпорту, не у браузері. Підкладка — OSM. При збоях Overpass workflow завершується помилкою, а не записує порожній файл.

## Обмеження прототипу
- Поки використано робочу прямокутну область навколо Бородянки, **не** офіційну межу населеного пункту.
- Лівий/правий бік відносно напрямку OSM way; це **не** електричні лінії.
- Лінії вулиць не розбиті за будинками; для тесту кольори детерміновано залежать від OSM ID.
- На сильних поворотах offset у пікселях приблизний; надалі потрібна обробка стиків.
- Фонові тайли вимагають інтернету. Дотримуватися політики використання tile.openstreetmap.org.
