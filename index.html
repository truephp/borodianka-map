Тест двох незалежних ліній для кожного сегмента OSM. Кольори вигадані для перевірки читабельності, не є даними ДТЕК. Геометрія завантажена з OSM у межах селища. Лінії — лише демонстрація, не стан електропостачання.

Усі зміни застосовуються у вкладці до експорту.
Будівля OSM

Visicom: лише картографічна підкладка. Геометрія й адресні кандидати з Data API ще не підключені. Збіг не підтверджений.
